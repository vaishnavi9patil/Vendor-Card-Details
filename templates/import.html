How it works

  • The first row should contain column names such as Company, Contact Name, Phone, Email, Website, Address, Destinations. Other names like "Mobile No", "Email ID" or "Agency" are recognised too.
  • Several phone numbers, emails or destinations can go in one cell, separated by commas, semicolons or new lines.
  • Duplicates are found automatically - against vendors already saved and inside the file itself (same email; same company and contact, even written as "Pvt Ltd" or with a shorter name; or same phone and contact). You choose to merge, add as new or skip each one before anything is saved.
  • Importing several files? Import them one after the other - the second file is checked against the first.
  • Files downloaded from this app's Download Excel can be imported back.
